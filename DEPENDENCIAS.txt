DEPENDÊNCIAS NOVAS

No terminal do projeto corretor-gabarito, execute:

npm install jspdf docx

Depois:

npm run build

git add .
git commit -m "Adiciona gabarito A4 e leitura OMR"
git push origin main

- App.tsx
- GabaritoGenerator.tsx
- OMRScanner.tsx
