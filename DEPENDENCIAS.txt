# Dependências e estrutura

As dependências usadas pelo projeto já estão declaradas em `package.json`.

Instalação:

```bash
npm install
```

Desenvolvimento:

```bash
npm run dev
```

Build:

```bash
npm run build
```

## Principais arquivos

- `src/App.tsx` — aplicação principal e navegação.
- `src/GabaritoGenerator.tsx` — geração da folha de gabarito.
- `src/OMRScanner.tsx` — leitura OMR pela câmera.
- `src/exportExcel.ts` — exportação das notas e resultados.
- `src/firebase.ts` — inicialização do Firebase.
- `src/index.css` — estilos globais.
- `public/manifest.webmanifest` — configuração PWA.

O projeto não utiliza mais o leitor de QR Code que fazia parte de uma versão anterior.
